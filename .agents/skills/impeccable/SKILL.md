# Impeccable Design System & Quality Assurance Skill

Impeccable is a design language and quality assurance harness created by Paul Bakaus (@pbakaus) designed to elevate frontend code generated by AI coding agents, eliminating "AI slop" (generic templates, overused Inter font overloads, repetitive nested cards, and jittery layout shifts).

---

## 🎨 Core Design Laws

### 1. Color System & Contrast
- **Palettes:** Use curated, harmonious color palettes (e.g. Tailwind Slate/Zinc neutrals with Teal/Cyan `#20D0D4` or `#4EACAF` brand accents). Avoid plain red, plain blue, or generic purple-to-blue gradients.
- **Contrast & Legibility:** Text must satisfy WCAG AA contrast ratios (minimum 4.5:1 for normal text). Never use light gray text on light colored backgrounds.
- **Color Intent:** Reserve bold accent colors for primary CTAs and key interactive states. Secondary elements should use subtle muted tones.

### 2. Spatial Rhythm & Spacing
- **Consistent Grid:** Use 4px / 8px incremental spatial rhythm (`gap-1.5`, `gap-2`, `gap-3`, `gap-4`, `p-4`, `p-6`).
- **Layout Stability (No Jittering):** Interactive toolbars, tabs, and filters must use fixed or reserved spatial containers so toggling options never shifts adjacent buttons or causes horizontal/vertical layout jumping.
- **Card Hierarchy:** Avoid excessive "card inside card inside card" nesting. Use subtle dividers (`border-slate-100`) or subtle background shifts (`bg-slate-50/80`) to group related information.

### 3. Typography & Text Hierarchy
- **Font Stack:** Use clean, modern sans-serif typography (`Inter`, `Plus Jakarta Sans`, `Outfit` or system UI fallbacks) with explicit font weights (`font-medium`, `font-semibold`, `font-bold`, `font-extrabold`).
- **Scale:** Maintain clear heading hierarchy (`text-xl font-bold` > `text-base font-semibold` > `text-xs text-slate-500`).
- **Line Height & Truncation:** Ensure proper line heights (`leading-snug`, `leading-tight`) and use text truncation (`truncate`, `line-clamp-2`) for unpredictable text lengths.

### 4. Interactive Polish & Micro-animations
- **Feedback:** All interactive buttons and controls must have visible hover, active, and focus states (`hover:bg-slate-100`, `active:scale-98`, `transition-all duration-150`).
- **Shadows & Glassmorphism:** Use soft, natural shadows (`shadow-2xs`, `shadow-xs`, `shadow-sm`) instead of heavy black shadows.

## 🛠️ Impeccable Playbook Commands

### `/impeccable audit`
Scans the active UI component or page for design anti-patterns:
- Checks WCAG contrast ratios.
- Verifies layout stability across dynamic states.
- Audits responsive alignment on mobile/tablet/desktop breakpoints.

### `/impeccable polish`
Refines an existing component:
- Polishes padding, margins, borders, and shadows.
- Enhances hover/active transitions.
- Standardizes icon sizes (`w-4 h-4`, `w-5 h-5`) and text colors.

### `/impeccable craft`
Builds a new UI component from scratch following the Impeccable design principles.

## 🛑 Anti-Pattern Checklist (AI Slop Prohibition)
1. ❌ **NO Layout Jitter:** Never conditionally render elements inline if they alter the dimensions of neighbor controls.
2. ❌ **NO Low Contrast:** Never use light gray text on light colored backgrounds.
3. ❌ **NO Raw Scrollbars:** Use custom styled or hidden scrollbars for horizontal scroll containers.
4. ❌ **NO Hardcoded Pixels:** Avoid arbitrary static pixel offsets (`top-[13px]`) when dynamic flex/grid can handle centering naturally.
5. ❌ **NO Missing States:** Every button must have hover, focus, and disabled states.
